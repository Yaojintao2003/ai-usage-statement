# AI 使用声明模板

> 面向研究生学位论文的「人工智能使用声明」填空模板。
>
> 依据：中国学位与研究生教育学会《规范研究生学位论文与实践成果中人工智能工具使用指南》（教育部学位管理与研究生教育司委托研制，2026-05-14 发布）

## 这是什么

2026 年 5 月起，研究生在学位论文中使用人工智能工具，需主动出具「人工智能使用声明」，原则上包括工具的**名称、版本号、官方网址、具体用途、具体环节、参数设置、验证过程**（指南第七条）；答辩环节还可能被要求提供**可追溯或可验证的依据**（第八条）。

这个仓库把上述要求整理成六个部分的填空表，可以直接填。

## 文件

| 文件 | 用途 |
|---|---|
| [`AI使用声明_模板.md`](./AI使用声明_模板.md) | 空白模板，复制后填写 |
| [`示例_已填写.md`](./示例_已填写.md) | 填好的例子，用来看颗粒度 |

## 怎么用

1. 复制 `AI使用声明_模板.md` 到你的论文目录
2. 逐项填写，`______` 处填内容，`[ ]` 处打勾
3. 按你所在学校要求的位置附上（通常在致谢后，或单独提交）

## 填写要点

- **版本号别空着**：查不到就写「网页版，未标注版本，最后使用日期 X 月 X 日」。空着最糟。
- **「辅助写作」四个字等于没说**：写到「第 3 章文献综述的初稿框架」这个粒度。
- **第四部分比第一部分重要**：审查看的是你**核了什么**，不是用了什么。

## 边界（请务必读）

- **这不是官方模板。** 指南第九条要求各学位授予单位结合学科特点制定细则，**你所在学校的要求优先**。使用前请查本校研究生院通知。
- **这不是法律意见**，也不构成任何形式的合规保证。
- **这不是免责条款。** 指南第四条明确：学位申请人对学位论文或实践成果的全部内容承担**最终责任**。
- 本模板只协助**如实披露**，不用于规避任何审查。
